# Системные требования

## Минимальная конфигурация (для разработки / тестирования)

| Ресурс | Значение |
|--------|----------|
| vCPU | 2 ядра |
| RAM | 2 GB |
| Диск | 60 GB SSD |
| ОС | Linux (Ubuntu 20.04+ / Debian 11+) |

> ✅ **Проверено на:** `vm.nano` (2 vCore / 2 GB / 60 GB SSD) — система запускается и обрабатывает единичные запросы.(hostkey)

## Рекомендуемая конфигурация (для production)

| Ресурс | Значение |
|--------|----------|
| vCPU | 4+ ядра |
| RAM | 8+ GB |
| Диск | 100+ GB NVMe SSD |

### Распределение памяти по сервисам

| Сервис | Рекомендуемый лимит RAM |
|--------|--------------------------|
| PostgreSQL | 2-4 GB |
| ML Service | 2-3 GB (зависит от размера модели) |
| Backend | 512 MB - 1 GB |
| Calc Service | 256-512 MB |
| Frontend (Nginx) | минимально |

## Создание сети Docker

Перед запуском необходимо создать общую сеть:

```bash
docker network create docker_web-network
```
