# О проекте

## Risk-Predictor: Шунтирование на минималках

**Полное название:** Разработка модуля прогнозирования риска осложнений после аорто-коронарного шунтирования (АКШ) на основе анализа клинических данных.

---

## Проблема

Аорто-коронарное шунтирование (АКШ) — одна из самых распространённых кардиохирургических операций в мире. Несмотря на отработанную технику, риск послеоперационных осложнений остаётся значительным:

- Летальность
- Острый инфаркт миокарда
- Острое почечное повреждение
- Сепсис
- Дыхательная недостаточность
- Послеоперационный делирий

Традиционные шкалы (EuroSCORE II) оценивают **только общую летальность** и имеют ограниченную точность на локальных популяциях.

---

## Решение

Мы создали программный инструмент, который на основе **накопленных клинических данных** и **ансамбля ML-моделей** количественно оценивает вероятность развития послеоперационных осложнений у конкретного пациента.

### Что умеет система:

-  **Рассчитывает 10+ клинических шкал** — EuroSCORE II, CCI, CRUSADE, Caprini, CHA₂DS₂-VASc и другие
-  **Прогнозирует риск по множеству целей** — отдельная модель для каждого осложнения
-  **Визуализирует результат** — цветовая индикация «светофор», детализация по целям
-  **Обновляется без остановки** — загрузка новой модели через `/reload`
-  **Разворачивается за 5 минут** — Docker Compose, единая команда запуска

---

## Научная база

Модели обучены на реальных клинических данных. Ансамбль включает:

| Алгоритм | Роль |
|----------|------|
| **CatBoost** | Основной классификатор для каждого осложнения |
| **TabNet** | Альтернативная нейросетевая модель с интерпретацией |

Две ветки ансамбля — отдельно для операций **с искусственным кровообращением (pump)** и **без ИК (off-pump)**.

---

## Статус проекта

Проект находится в стадии активной разработки. Текущая версия — `v3`.

-  Backend API
-  Calc Service (10+ шкал)
-  ML Service (ансамбль CatBoost + TabNet)
-  Frontend (React SPA)
-  CI/CD (автоматический деплой)
-  Накопление данных, улучшение моделей
